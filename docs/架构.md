# OneHub 架构说明

## 1. 全景

```
┌────────────────────────── 浏览器 ──────────────────────────┐
│  React SPA(ark-ui endfield × maximal)                      │
│  账号矩阵 → 文件浏览 → 预览面板 / 下载                        │
│  只接触: 账号展示名、文件元数据、临时下载直链                   │
└───────────────┬───────────────────────────────────────────┘
                │ /api/*  (fetch, JSON)
┌───────────────▼───────────────────────────────────────────┐
│  Cloudflare Worker(onehub)                                │
│  ├─ ASSETS 绑定: frontend/dist 静态资产(SPA 回退)          │
│  ├─ auth/:  密码门(HMAC 签名 Cookie) + KV 限速             │
│  ├─ routes/: health / gate / accounts / items / file /     │
│  │           download(302) / raw(≤2MB 流代理) /            │
│  │           admin(仅本地: 增删改/设备码, 线上 404)         │
│  ├─ admin/: 管理台网关 + 设备码/企业版授权流程(仅本地)       │
│  ├─ onedrive/:                                             │
│  │   ├─ personal: refresh_token 换发 + 轮换回写 KV          │
│  │   ├─ business: client_credentials + /users/{upn}/drive  │
│  │   └─ tokenCache: KV 缓存 access_token(TTL≈55min)        │
│  └─ config/: 账号注册表(KV accounts:index / account:<id>)  │
└───────────────┬───────────────────────────────────────────┘
                │ HTTPS
        ┌───────▼────────┐
        │ Microsoft Graph │  v1.0
        └────────────────┘
```

## 2. 关键设计决策

| 决策 | 理由 |
|---|---|
| 单 Worker 同托管页面与 API | 单域名免 CORS;免费额度 10 万请求/天;部署一次到位 |
| 双认证策略按账号类型分流 | 个人版无法用 client credentials;企业版用应用密钥不依赖人工定期重授权 |
| token 存 KV 而非 Worker Secret | 账号数量动态、需脚本化管理;KV 静态加密,仅 Worker 可读 |
| refresh_token 轮换回写 | Microsoft 每次刷新签发新 refresh_token,不回写会在闲置 90 天后失效 |
| 下载 302 直链(不走代理) | 需求明确"直接推 OneDrive 链接";大文件不经 Worker,省流量配额 |
| raw 仅限 ≤2MB 文本 | 规避浏览器 CORS;大文件预览本就该走专用渲染(Office Viewer/媒体标签) |
| 密码门用 HMAC Cookie 而非 session 存储 | Worker 无粘性会话;无状态验证,限速计数放 KV |
| 账号管理台仅本地(`ADMIN_MODE=local`) | 高权限入口不进公网:无管理密码暴破面/Cookie 窃取面;本地改完 `account:sync` 即可 |
| wrangler 配置模板化生成 | 仓库可开源:真实 KV id 只经环境变量注入,仓库与新增 git 历史零标识符 |

## 3. 请求时序(以"打开一号机某目录"为例)

```
前端                     Worker                          Graph
 │ GET /api/accounts       │                               │
 │────────────────────────►│ 读 accounts:index ─┐           │
 │◄───[{id,name},...]──────│ (无凭据)           │           │
 │ GET /accounts/a1b2?path=/docs (路由)                     │
 │ GET /api/accounts/a1b2/items?path=/docs                 │
 │────────────────────────►│ 取 token: 缓存命中? ──否──► POST /consumers|{tenant}/token
 │                         │   (personal: 新 refresh_token 回写 KV)          │
 │                         │ GET /me/drive/root:/docs:/children ──►
 │                         │◄─ children(分页聚合) ─────────────┘
 │◄───{path,items}─────────│
```

## 4. 模块边界(monorepo)

| 目录 | 职责 | 依赖 |
|---|---|---|
| `worker/` | 全部服务端逻辑 | 无前端依赖;类型契约看 docs/api.md |
| `frontend/` | SPA;`shared/fileTypes.ts`、`shared/format.ts` 为纯函数可单测 | 仅 `/api/*` |
| `scripts/` | 账号管理 CLI(add/list/remove/sync),经 wrangler 读写 KV | KV id 来自 `.dev.vars`/环境变量(注入生成配置) |
| `docs/` | 契约与教程 | — |

feature 级前端模块间禁止互相 import(见 AGENTS.md §3)。

## 5. 失败模式与降级

| 故障 | 表现 | 处理 |
|---|---|---|
| personal refresh_token 失效 | 账号 `status=invalid` | 首页该卡片显示"授权失效",其余账号不受影响;本地管理台重新添加(或 CLI 同名覆盖)后 `account:sync` |
| Graph 5xx/限流 429 | 502 `GRAPH_UPSTREAM` | 前端提示稍后重试;Worker 对 429 读 Retry-After 原样返回 429 |
| downloadUrl 过期(>1h 的旧链接) | 微软 404/410 | 前端所有预览/下载入口每次现取 `/file/:id`,不缓存直链 |
| Office Viewer 加载失败 | iframe 空白 | 预览面板提供"下载查看"按钮常驻兜底 |
| 密码门暴破 | — | KV 计数限速(如 5 次/10 分钟/IP) |
